# Create Module

Use when implementing a new business domain.

## Process

1. Identify domain.
2. Define entities.
3. Define use cases.
4. Define database requirements.
5. Define permissions.
6. Define API requirements.
7. Define UI requirements.
8. Define tests.
9. Implement backend.
10. Implement frontend.
11. Document module.

## Required analysis

Before coding determine:

- What data exists?
- Who can access it?
- Who can modify it?
- What business rules exist?
- What external integrations are required?
