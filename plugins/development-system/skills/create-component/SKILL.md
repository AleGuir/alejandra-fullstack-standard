# Create Component

Use this workflow when creating a React component.

## Before creating

Search the existing component library.

Determine whether an existing component can be reused.

Do not create duplicates.

## Component responsibilities

A component should have a clear responsibility.

Avoid large components containing:

- API calls
- database logic
- complex business rules
- unrelated UI

## Process

1. Identify responsibility.
2. Check existing components.
3. Define props.
4. Define states.
5. Implement accessibility.
6. Implement responsive behavior.
7. Add tests when appropriate.
8. Verify TypeScript.
