# Naming Conventions

## TypeScript

Variables:

camelCase

Functions:

camelCase

Constants:

UPPER_SNAKE_CASE when truly constant/global.

Types:

PascalCase

Interfaces:

PascalCase

Components:

PascalCase

---

## Files

React components:

PascalCase.tsx

Hooks:

useSomething.ts

Services:

something.service.ts

Repositories:

something.repository.ts

Schemas:

something.schema.ts

Types:

something.types.ts

---

## Database

Tables:

snake_case

Columns:

snake_case

---

## APIs

Use nouns for resources.

Prefer:

/api/employees

/api/employees/{id}

/api/requests

Avoid unnecessary verbs.
